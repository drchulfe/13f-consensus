# 검증 설계와 해석 기준 (`scripts/robustness.py`)

## 1. 선도기업 대리변수 검증

질문: 선도기업 특허로 본 기술 추세가 생태계 전체 추세를 대표하는가?

- **지표** (기간별): 선도기업 vs 나머지의 군집 구성 코사인 유사도 / 첫 구간→마지막 구간 비중 증감의 Spearman 순위상관 /
  선행상관(선도기업의 앞 구간 변화 vs 나머지의 다음 구간 변화)
- **귀무분포**: 선도기업과 총 출원 건수가 비슷한 **무작위 출원인 묶음**(선도기업 제외) 300–500개.
  p = 무작위 묶음 중 선도기업보다 대표성이 낮게(유사도가 작게) 나온 비율.
- **강건성 격자**: k {8,10,12,14,16} × 초기값 5 × 선도기업 정의(통합, 단독 각각, 상위 3사).
  보고: 설정별 중앙값과 'p < .05인 설정 비율'.
- **해석 주의**: 단독 정의는 구간별 건수가 극히 적을 수 있다(예: 2건) → 본문은 통합·상위 3사, 단독은 강건성 표.
  순위상관은 군집 수(10여 개) 수준이라 검정력이 약하다 → 핵심 근거는 순열검정 유사도.

실제 결과 예시(한국 G06Q 40/08, 1,503건, 삼성생명+삼성화재 106건): 2016–19 유사도 0.58 vs 무작위 0.88(p=.017),
2020–22 0.48 vs 0.91(p<.001, 25개 설정 모두 유의), 2023–25 0.75 vs 0.84(p=.17) → "과거엔 대표하지 않았고 최근 수렴, 선행성 없음".

## 2. 등록 로지스틱 회귀

- 표본: 심사가 대부분 끝났을 기간의 출원 중 종결 상태(등록·소멸=1, 거절·취하·포기=0). '공개'(심사 중) 제외.
- 설명변수: 출원주체 유형(기준: 기타 기업). 공동출원은 우선순위(보험사 > 인슈어테크 > …)로 1개 유형.
- 통제: 출원연도 FE, 군집 FE, IPC 메인그룹 수, 청구항 길이. 표준오차 HC1.
- 보고: M1(유형만) → M2(+FE) → M3(+출원 특성)의 오즈비 변화. 출원인 유형을 전수 확정한 뒤 재추정.
- 해석 주의: 보험사 효과는 출원 역량(변리 조직)을 반영할 수 있다 — "기술이 우수하다"로 쓰지 않는다.

## 3. 연관규칙 유의성

- 규칙 X→Y마다 해당 군집·구간 부분집합에서 초기하분포 p = P(동시출현 ≥ 관측 | n, cnt(X), cnt(Y)).
- Benjamini–Hochberg로 q값. 서술은 q < .05 규칙 중심, 나머지는 우연과 구별되지 않는다고 명시.

## 4. 그 밖의 강건성 (논문 투고 전)

- 미공개 구간을 뺀 기간으로 재분석
- 임베딩 기반 군집(예: 문장 임베딩 + BERTopic)으로 같은 결론인지
- 확장 검색 데이터로 재분석(군집 안정성이 떨어질 수 있음을 보고)
- 출원인 유형 2인 독립 분류 κ
