# 실제로 결과를 틀리게 만든 함정들

각 항목은 한국 보험업 특허 분석 중 실제로 발생했고, 고친 방법을 함께 적었다.

## 데이터·출원인

1. **출원인 한글 음역과 현재 사명 표시.** KIPRIS는 2016년 출원도 출원인을 현재 사명으로 보여주며, 영문 약어를 한글로 음역한다
   ("디비손해보험", "케이비손해보험", "엘아이지손해보험"). 영문 표기만으로 매칭하면 해당 회사 출원이 0건이 된다.
   → 출원인 표기 목록을 먼저 뽑아 `FIRMS`를 맞춘다. 출원인코드가 사명 변경 후에도 같았으므로 코드 검색을 권한다.
2. **사명 변경.** 옛 사명(동부화재, LIG손해보험, 대한생명, 신한생명·오렌지라이프)이 따로 집계되면 한 회사가 두 줄로 나뉜다.
   → `canon()`으로 표준 회사명에 묶는다. 상위 출원인 표에서 한 회사가 두 번 나오는지 확인한다.
3. **쉼표가 들어간 출원인명.** "모터 테크놀로지스, 인코포레이티드"를 쉼표로 나누면 '인코포레이티드'가 별도 출원인이 된다.
   → KIPRIS 공동출원 구분자는 `|`이므로 `|`와 `;`로만 나눈다.
4. **공동출원 중복 계상.** 기업별 집계에서 공동출원은 각 회사에 1건씩 들어간다(full counting). 합계가 고유 건수보다 크다.
   → 보고서에 명시하고, 산업 전체 수치는 중복 제거한 고유 출원 기준으로 쓴다.
5. **같은 날 같은 제목의 출원.** 하나의 발명을 두 건으로 낸 경우가 있다(예: 블랙박스 AI 과실판정 2건). 소표본에서 IPC 결합이
   두 배로 잡혀 '융합 추세'로 보인다. → 발명 기준 건수를 함께 쓰고, 해석할 때 같은 묶음인지 확인한다.
6. **유형 분류가 이름만으로는 안 되는 주체.** 인슈어테크·헬스케어 기업은 이름 규칙으로 판별되지 않아 '기타 기업'에 쌓인다
   (생태계 출원의 35–43%). → 출원 제목으로 제안(`actor_draft.py`)하고 사람 2명이 확정, κ 보고.
7. **개인 판별 규칙의 오류.** 한글 2–4자 이름을 개인으로 보는 규칙은 짧은 법인명을 개인으로 분류할 수 있다.

## 시간

8. **출원 후 18개월 공개 지연(특허법 제64조).** 추출일 기준 18개월 이내 출원은 대부분 보이지 않는다. 최근 연도 감소는
   추세가 아니다. → `--asof`로 미공개 구간을 표시하고, 핵심 결론은 미공개 구간을 뺀 기간으로 재확인한다.
   보도된 연간 출원 수와 KIPRIS 건수가 크게 다르면 이 때문일 가능성이 높다.
9. **등록률 비교 기간.** 최근 출원은 심사 중이라 등록률이 구조적으로 낮다. → 심사가 대부분 끝났을 기간만 쓴다.

## 텍스트·분류

10. **명세서 문체가 군집을 만든다.** 특정 출원인(대리인)의 관용구("본 개시는", "컴퓨팅 장치", "프로세서·메모리",
    "판독 가능한 기록매체")가 남아 있으면 기술이 아니라 출원인별로 군집된다. → 군집별 최다 출원사 비중을 확인하고
    대표어에 이런 표현이 보이면 불용어에 넣는다.
11. **키워드 사전 분류의 오분류.** 소표본에서 사전 분류는 자주 틀렸다("인쇄물 견적" → 보상, "환경책임보험" → 헬스케어).
    → 수십 건 이하면 전수 수작업 분류가 낫고, 사전은 보조로만 쓴다.
12. **포괄적 키워드.** '고객', '모델', '인식'처럼 넓은 단어는 한 분야로 과다 분류된다. → 복합어로 바꾼다("고객관리").
13. **대표어 후보.** 군집 안에서 0번 등장한 단어가 대표어로 올라오는 버그가 있었다. → 군집 밖보다 안에서 더 흔한 단어만 후보.

## 통계

14. **보험 분류 코드 허브.** 생태계를 G06Q 40/08로 정의하면 이 코드가 모든 출원에 붙어 lift ≈ 1의 자명한 연결만 만든다.
    → 허브 코드를 뺀 동시출현 네트워크를 함께 본다.
15. **support 기준 없는 연관규칙.** 원 논문대로면 1건짜리 규칙(confidence 100%)이 통과하고, 한 특허 묶음의 하위조합이
    수십 개 규칙이 된다. → tidset 단위 중복 제거 + 초기하분포 검정·BH 보정. 서술은 q < .05 중심.
16. **소표본 RTA.** 1–2건으로 RTA가 3–7이 된다. → 건수 병기, 그림에는 출원 9건 이상 기업만.
17. **두 분석의 군집은 다르다.** 산업 분석과 생태계 분석은 따로 군집했으므로 이름이 비슷해도 같은 군집이 아니다.

## 실행 환경

18. **파이썬 버전.** `pd.ExcelWriter.to_excel(xw, "시트")`처럼 시트명을 위치 인수로 주면 최신 pandas에서 오류 → `sheet_name=`.
19. **한글 그림.** matplotlib 기본 폰트는 한글이 깨진다 → `koreanize-matplotlib`. 로그축 마이너스 기호 경고는 눈금 라벨을 직접 지정.
20. **병합 키 자료형.** 출원번호를 엑셀에서 읽으면 숫자가 되어 문자열 열과 병합이 실패한다 → 양쪽을 `str`로.
21. **긴 계산은 중간 저장.** 순열검정은 수십 분 걸린다. 결과를 먼저 저장한 뒤 다음 단계로 간다(`robustness.py`의 캐시).
